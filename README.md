# StreamTV - Plateforme de Streaming Gratuite

![StreamTV Screenshot](https://iili.io/KpgBNJp.md.png)

StreamTV est une plateforme de streaming moderne et responsive qui permet de regarder des films, séries et chaînes de télévision en direct gratuitement.

## ✨ Fonctionnalités

- **Interface Moderne** : Design épuré avec palette de couleurs bleu et rose
- **Responsive** : S'adapte à tous les appareils (desktop, tablette, mobile)
- **Lecteur Vidéo Intégré** : Visionnage en direct avec contrôles avancés
- **Mode Plein Écran** : Expérience immersive avec bouton dédié
- **Navigation Intuitive** : Menu clair et barre de recherche
- **Cartes de Chaînes** : Présentation élégante avec logos et descriptions

## 🎬 Chaînes Disponibles

- **Canal+ Cinéma** - Films de tous genres
- **Bein Sport 1** - Événements sportifs en direct
- **France 24** - Actualités internationales
- **Boomerang** - Dessins animés pour enfants

## 🛠️ Technologies Utilisées

- **HTML5** - Structure sémantique
- **CSS3** - Styles modernes avec variables CSS et Flexbox/Grid
- **JavaScript** - Interactivité et gestion du lecteur
- **Font Awesome** - Icônes vectorielles
- **CDN** - Librairies externes optimisées

## 🚀 Installation

1. Clonez le repository :
```bash
git clone https://github.com/tresormika/streamtv.git
```

2. Ouvrez le fichier `index.html` dans votre navigateur

3. Ou déployez sur votre serveur web préféré

## 📁 Structure du Projet

```
streamtv/
│
├── index.html          # Fichier principal
```

## 🎮 Utilisation

1. **Accueil** : Page d'accueil avec présentation des chaînes
2. **Navigation** : Utilisez le menu pour accéder aux différentes sections
3. **Recherche** : Barre de recherche pour trouver du contenu spécifique
4. **Visionnage** : 
   - Cliquez sur "Regarder maintenant" sur une carte de chaîne
   - Utilisez le bouton plein écran pour une expérience immersive
   - Fermez le lecteur avec la croix ou la touche Échap

![Lecteur Vidéo](https://iili.io/KpgTiGt.md.png)

## 🌟 Fonctionnalités Avancées

### Lecteur Vidéo
- **Mode Plein Écran** : Bouton dédié avec icône dynamique
- **Contrôles au Clavier** : Échap pour quitter le plein écran
- **Interface Adaptative** : S'adapte à la taille de l'écran
- **Fermeture Intelligente** : Cliquez à l'extérieur pour fermer

### Design Responsive
- **Grid CSS** : Layout adaptatif des cartes de chaînes
- **Media Queries** : Optimisation mobile et tablette
- **Animations Fluides** : Transitions CSS pour une UX améliorée
